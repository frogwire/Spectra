Spectra fonts (bundled; nothing is fetched at runtime):

  Space Grotesk (wordmark, headings): SpaceGrotesk-Medium.ttf, -SemiBold.ttf, -Bold.ttf
  Inter (interface text): Inter-Variable.ttf  (the variable font: one file, every weight)

Licenses: OFL-SpaceGrotesk.txt, OFL-Inter.txt (SIL Open Font License 1.1; must ship with the app).
Only put files the app uses in this folder: everything in assets is packed into the APK.
Missing files fall back to the system sans-serif font.
