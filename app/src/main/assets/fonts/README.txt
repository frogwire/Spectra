Spectra fonts go here (static .ttf files, exact names):

  SpaceGrotesk-Medium.ttf  SpaceGrotesk-SemiBold.ttf  SpaceGrotesk-Bold.ttf
  Inter-Regular.ttf  Inter-Medium.ttf  Inter-SemiBold.ttf  Inter-Bold.ttf

Get them from fonts.google.com (Space Grotesk, Inter) -> "Get font" -> Download.
In each zip, use the files in the "static" folder. Inter's static files may be named
like "Inter_18pt-Regular.ttf"; rename them to the names above.

Both fonts are SIL Open Font License 1.1: also copy each OFL.txt here
(e.g. OFL-SpaceGrotesk.txt, OFL-Inter.txt) and list them in the app's licenses screen.

Missing files fall back to the system sans-serif font.
